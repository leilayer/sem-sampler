# SEM Sampler 使用说明

为 TESCAN MIRA3 的 SEM 表征设计的小工具：① 按四角坐标随机分区取点；② 在薄膜示意图上浏览已拍图像。

## 启动
1. 把整个文件夹放在任意位置（路径里有中文没关系）。
2. 双击 `Start_SEM_Sampler.bat`。
   - 第一次运行会自动建立运行环境（需要联网，大约 1 分钟）。
   - 如果提示找不到 Python：去 https://www.python.org/downloads/ 安装 Python 3，安装时勾选 **Add python.exe to PATH**，然后再双击一次。
3. 之后每次双击都会直接打开程序。

## ① 取点规划（上机前）
1. 粘贴或打开记录四角坐标的 txt（格式同现有记录：样品名 + top-left / top-right / bottom-left / bottom-right）。
   - 角点按"SEM 画面里看到的"上下左右来定义。
2. 设置参数：
   - **边缘排除宽度**：这一圈内不放随机点。
   - **区域行数 × 列数**：每个区域里随机取 1 个点。
   - **边缘参考点**：每片在上 / 下 / 左 / 右边缘各加 1 个点，标为 `edge`，和随机点分开统计。
   - **配对模式**：所有样品使用同一组相对位置 (u, v)，方便样品之间比较。
3. 点 **生成第 1 轮**。现场觉得点不够，就点 **追加一轮随机点**（每个区域再随机加 1 个点）。
4. 一定要 **保存项目 (.json)**，最好放进当天的 SEM 数据文件夹。
5. **导出点位图 (.png)** 打印带进 SEM 室：每次装样一张图，表格最后一列可以手动打勾。
   - 程序里双击表格某一行，会把该点的 X、Y 复制到剪贴板。

**建议文件名**：`批次_样品_点号_倍率.tif`，例如 `SA261105b_N7_R1-P05_50kx.tif`。

**随机性纪律**：到了点位就拍，落在裂缝或空白处也照拍；额外挑"好看区域"拍的图请单独标注（例如文件名加 `_sel`）。

## ② 图像浏览（拍完后）
1. **选择图像文件夹**：程序直接从 tif 内嵌的元数据读取载物台坐标和倍率，不需要 .hdr，也不依赖文件名里写的倍率。
   - 文件夹里如果有角点 txt 或项目 json，会自动加载。
2. 圆点 = 拍摄位置：颜色表示该位置的最高倍率，圆点越大表示拍的张数越多。虚线方框 = 计划点，红色表示还没拍。
3. 鼠标**悬停**在圆点上会显示该位置所有倍率的预览；**单击**圆点，会用系统默认的照片程序打开原图（拍了多张时先弹出选择窗口）。
4. 右侧列表**双击**也能打开原图。
5. **载物台视图**：和 SEM 画面方向一致；不同次装样的样品自动分开画。**归一化视图**：每片膜画成同样大小的方块，方便横向比较。

## 文件说明
- `sem_sampler_app.py`：程序界面
- `sem_core.py`：坐标换算、取点、读取元数据
- 预览缩略图缓存在 `%LOCALAPPDATA%\SEMSampler\thumbs`，可以随时删除。
